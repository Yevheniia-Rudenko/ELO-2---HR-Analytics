# HR Analytics Datasets List

This document provides a list of datasets that can be used for an HR Analytics project, including real links and short descriptions.

---

## 1. IBM HR Analytics Employee Attrition & Performance

**Link:** <https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset/data>

**Description:**
The most of study, simulation and training projects that I reviewed use this dataset from IBM. Dayaset includes 35 fields that comtain sufficient volume of information to calculate significunt KPIs, invesrigate relations between diffrent categories, make predictions. Include "attrition" field. 

**Usage for the project**
I find this dataset the best for the purpose of study, modeling and simulation.

## 2. Employee Attrition Using Machine Learning

**Link:** <https://www.kaggle.com/datasets/comrade1234/employee-attrition-using-machine-learning>

**Description:**
This dataset includes more lines (cortege) of data 5000, but fewer fields - only 10, comparing to dataset #1. 

**Usage for the project**
This dataset is better for prediction purposes because it include three times bigger volum of data but worse for the purpose of investigation correlations between different categories. Since we want to realise both forecasting and correlation tasks, I find the dataset #1 better.
