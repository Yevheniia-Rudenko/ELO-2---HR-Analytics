# HR Analytics Datasets List

This document provides a list of datasets that can be used for an HR Analytics project, including real links and short descriptions.

---

## 1. IBM HR Analytics Employee Attrition & Performance

**Link:** <https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset/data>

**Description:**
The most of study, simulation and training projects that I reviewed use this dataset from IBM. The dataset includes 35 fields that contain sufficient volume of information to calculate significunt KPIs, investigate relations between different categories, make predictions. It includes "attrition" field.

**Usage for the project**
I find this dataset the best for the purpose of study, modelling and simulation project.

## 2. Employee Attrition Using Machine Learning

**Link:** <https://www.kaggle.com/datasets/comrade1234/employee-attrition-using-machine-learning>

**Description:**
This dataset includes more lines (corteges) of data 5000, but fewer fields - only 10, comparing to dataset #1.

**Usage for the project**
This dataset is better for prediction purposes because it include three times larger volum of data but worse for the purpose of investigation correlations between different categories. Since we want to realise both forecasting and correlation tasks, I find the dataset #1 better.
