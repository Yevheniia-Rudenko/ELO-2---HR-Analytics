# 📚 Посібник користувача: HR Analytics Platform

## 🎯 Що це за платформа?

**HR Analytics Platform** — це інтерактивна веб-платформа для аналізу даних про співробітників та прогнозування плинності кадрів (employee attrition).

### Де можна використовувати цю платформу?

✅ **HR-відділи компаній** — моніторинг задоволеності співробітників, виявлення факторів ризику звільнення

✅ **Менеджери** — оцінка ефективності команди, аналіз work-life balance

✅ **Бізнес-аналітики** — прогнозування плинності кадрів, аналіз трендів

✅ **Керівництво компанії** — стратегічні рішення щодо управління персоналом

✅ **Навчальні заклади** — демонстрація можливостей data analytics у HR

   - **Overview** (Огляд)

---

### Крок 2: Розділ "Overview" — Дашборд з аналітикою

**Що тут можна побачити:**

#### 📊 Ключові показники (KPI Cards)

- **Total Employees**: Загальна кількість співробітників (1,470)
- **Attrition Rate**: Відсоток плинності кадрів (16.1%)
- **Average Age**: Середній вік співробітників (37 років)
- **Avg Monthly Income**: Середня заробітна плата ($6,503)

#### 📈 Інтерактивні графіки

1. **Attrition by Department** (Плинність по відділах)
   - Показує, в яких відділах найбільше звільнень
   - Допомагає виявити проблемні підрозділи

2. **Age Group Analysis** (Аналіз по віковим групам)
   - Порівняння співробітників, які залишилися vs. пішли
   - Виявлення вікових груп з найбільшим ризиком

3. **Overtime Impact** (Вплив переробок)
   - Як переробки впливають на рішення звільнитися
   - Критично важливий показник для work-life balance

4. **Work-Life Balance Rating** (Оцінка балансу роботи і життя)
   - Розподіл оцінок від 1 (погано) до 4 (відмінно)
   - Допомагає зрозуміти загальний стан

**Як користуватися:**

- Наводьте курсор на графіки, щоб побачити детальні цифри
- Графіки автоматично оновлюються при зміні даних

---

### Крок 3: Розділ "Questionary" — Опитування співробітників

**Для чого:**

- Збір даних про задоволеність роботою
- Виявлення факторів, що впливають на рішення залишитися/піти
- Аналіз work-life balance

**Як заповнити опитування:**

1. **Age** (Вік): Введіть ваш вік (18-65 років)

2. **Department** (Відділ): Виберіть зі списку
   - Sales (Продажі)
   - Research & Development (Дослідження та розробка)
   - Human Resources (HR)

3. **Job Satisfaction** (Задоволеність роботою): Оцініть від 1 до 5
   - 1 = Дуже незадоволений
   - 5 = Повністю задоволений

4. **Work-Life Balance**: Оцініть від 1 до 4
   - 1 = Дуже погано
   - 4 = Відмінно

5. **Monthly Income** (Місячний дохід): Введіть суму в доларах

6. **Overtime** (Переробки): Так/Ні

7. **Comments** (Коментарі): Додаткова інформація

**Що відбувається після відправки:**

- Дані зберігаються локально (у режимі демо)
- Або надсилаються до BigQuery (якщо увімкнена інтеграція з GCP)
- Виводиться повідомлення про успішну відправку

---

### Крок 4: Розділ "Managers Appraisal" — Оцінка від менеджерів

**Для чого:**

- Оцінка продуктивності співробітників менеджерами
- Виявлення high performers і зон розвитку
- Планування кар'єрного росту

**Як заповнити оцінку:**

1. **Employee Name** (Ім'я співробітника): ПІБ

2. **Department** (Відділ): Виберіть відділ

3. **Job Role** (Посада): Наприклад, "Sales Executive", "Research Scientist"

4. **Performance Rating** (Оцінка продуктивності): 1-4
   - 1 = Низька
   - 4 = Відмінна

5. **Years at Company** (Років у компанії): Стаж роботи

6. **Promotion Potential** (Потенціал до підвищення):
   - Low (Низький)
   - Medium (Середній)
   - High (Високий)

7. **Manager Comments** (Коментарі менеджера): Детальна оцінка

**Що відбувається після відправки:**

- Оцінка зберігається в базі даних
- Дані можуть використовуватися для аналітики та прогнозування

## 🔧 Технічні можливості платформи

### Режим 1: Демонстраційний (за замовчуванням)

**Що робить:**

- Використовує попередньо завантажені дані (1,470 записів)
- Працює без інтернету
- Не потребує налаштування GCP
- Ідеально для презентацій і навчання

**Як використовувати:**

1. Просто відкрийте `index.html`
2. Все працює "з коробки"

---

### Режим 2: Реальна інтеграція з Google Cloud (опціонально)

**Що робить:**

- Підключається до реальної бази даних BigQuery
- Дані оновлюються в реальному часі
- Форми зберігають дані в cloud
- Підходить для production використання

**Як увімкнути:**

#### Крок 1: Налаштування GCP

1. Створіть проект у Google Cloud Console
2. Увімкніть BigQuery API
3. Створіть dataset `IBMAnalytics`
4. Завантажте дані у таблицю `employee_attrition`

#### Крок 2: Налаштування API

1. Відкрийте `api_server.py`
2. Замініть `YOUR_GCP_PROJECT_ID` на ваш реальний project ID
3. Створіть service account і завантажте JSON ключ
4. Встановіть змінну середовища:

   ```bash
   export GOOGLE_APPLICATION_CREDENTIALS="path/to/your/key.json"
   ```

#### Крок 3: Запуск API сервера

```bash
cd 6_final_presentation/hr_portfolio_site
pip install -r requirements.txt
python3 api_server.py
```

#### Крок 4: Увімкнення в інтерфейсі

1. Відкрийте `js/app.js`
2. Змініть `USE_GCP_INTEGRATION = true`
3. Оновіть сторінку в браузері

**Готово!** Тепер платформа працює з реальними даними.

## 🆘 Частi питання (FAQ)

### Q: Чи потрібен інтернет для роботи?

**A:** Ні, в демо-режимі платформа працює повністю офлайн.

### Q: Чи зберігаються дані з форм?

**A:** У демо-режимі — локально в браузері. З GCP — в BigQuery.

### Q: Скільки коштує використання GCP?

**A:** BigQuery має безкоштовний рівень (10 GB зберігання, 1 TB запитів/місяць). Для невеликих компаній це безкоштовно.

### Q: Чи можна кастомізувати графіки?

**A:** Так, всі графіки налаштовуються через `js/app.js`.

### Q: Чи підтримується мобільна версія?

**A:** Так, платформа повністю responsive і працює на всіх пристроях.

### Q: Чи можна експортувати дані?

**A:** Так, з BigQuery можна експортувати дані в CSV, JSON, або підключити Power BI / Tableau.

### Q: Як додати нових співробітників?

**A:** Через форми Questionary/Appraisal або прямо в BigQuery.
