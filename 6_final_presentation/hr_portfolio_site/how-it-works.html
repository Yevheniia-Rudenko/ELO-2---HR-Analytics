🎯 How It Works

A comprehensive guide to understanding, using, and integrating the HR Analytics Platform for data-driven workforce management

📚 What is This Project?

The HR Analytics Platform is an interactive web-based solution designed to help organizations analyze employee data, predict attrition risks, and make data-driven decisions about workforce management. Built as part of the MIT Emerging Talent program, this platform demonstrates the power of combining modern web technologies with cloud-based data analytics.

📊 Real-Time Analytics

Interactive dashboards with live KPIs showing employee metrics, attrition rates, and satisfaction scores

🔮 Predictive Insights

Data-driven analysis to identify attrition risk factors and workforce trends

☁️ Cloud-Ready

Optional Google Cloud Platform integration for scalable, real-time data processing

📱 Responsive Design

Works seamlessly on desktop, tablet, and mobile devices

🔒 Secure & Private

Built with security best practices, supporting both demo and production modes

🎨 User-Friendly

Intuitive interface designed for HR professionals, managers, and employees

💼 Real-World Use Cases

🏢 Case 1: HR Department - Monthly Review

Scenario: HR Manager reviews monthly attrition trends

Process:

  1. Opens Overview dashboard
  2. Checks Attrition Rate KPI (16.1% - above target 13%)
  3. Analyzes Department chart - Sales has highest attrition
  4. Reviews Overtime Impact - 30% of overtime workers leave
  5. Takes action: Reduces overtime, improves work-life balance

Result: Data-driven decision prevents further attrition

👤 Case 2: Employee - Quarterly Survey

Scenario: Employee fills out satisfaction survey

Process:

  1. Navigates to "Employee Questionary" tab
  2. Fills out form: Age, Department, Job Satisfaction, Work-Life Balance
  3. Adds comment about heavy workload
  4. Submits form (saved locally or to BigQuery)

Result: HR receives early warning about potential issues

👔 Case 3: Manager - Performance Review

Scenario: Manager evaluates team member for promotion

Process:

  1. Goes to "Managers Appraisal" section
  2. Enters employee details and performance rating (4/4)
  3. Indicates high promotion potential
  4. Submits evaluation

Result: Data available for HR talent management decisions

💼 Case 4: Executive - Strategic Planning

Scenario: CEO reviews workforce analytics for budget planning

Process:

  1. Reviews all dashboards and trends
  2. Analyzes age distribution and tenure patterns
  3. Identifies departments needing investment
  4. Plans retention programs and hiring strategy

Result: Strategic decisions backed by data

🔌 How to Integrate This Platform

Option 1: Standalone Deployment (Simple)

# Deploy to GitHub Pages (Free) git checkout -b gh-pages cp -r 6_final_presentation/hr_portfolio_site/* . git add . git commit -m "Deploy HR Analytics" git push origin gh-pages # Your site: https://username.github.io/repo-name/

Option 2: Company Intranet Integration

Embed into existing company portals:

<!-- In your company intranet --> <iframe src="https://your-hr-analytics.com" width="100%" height="800px" frameborder="0" ></iframe>

Option 3: Google Cloud Integration (Advanced)

Step-by-Step GCP Integration:

  1. Create GCP Project - Set up new project in Google Cloud Console
  2. Enable BigQuery API - Activate data warehouse service
  3. Create Dataset & Table - Set up IBMAnalytics.employee_attrition
  4. Upload Data - Import your employee CSV data
  5. Create Service Account - Generate authentication credentials
  6. Deploy API Server - Run Flask app on Cloud Run
  7. Update Frontend - Set USE_GCP_INTEGRATION = true
  8. Test Integration - Verify real-time data flow
# Quick GCP Setup Commands gcloud projects create your-project-id gcloud services enable bigquery.googleapis.com bq mk --dataset your-project-id:IBMAnalytics bq load --source_format=CSV \ your-project-id:IBMAnalytics.employee_attrition \ data.csv schema.json
